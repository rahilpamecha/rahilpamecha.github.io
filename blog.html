My Journey from MCA Graduate to Software Professional at Barclays

Looking back at my career journey — from studying Computer Applications at Lovely Professional University to building enterprise software at Barclays — I've learned that success in tech isn't just about coding skills. It's about perseverance, continuous learning, and the ability to adapt to new challenges.

When I graduated with my MCA degree with a 91.3% score, I knew I wanted to work in a company where I could make a real impact. The financial technology sector offered exactly that — complex problems, massive scale, and the opportunity to build systems that millions of people rely on every day.

My advice to aspiring software professionals: invest in your fundamentals. Understanding data structures, algorithms, and object-oriented programming deeply will serve you throughout your career, regardless of which specific framework or language is trending.

5 Key Lessons I Learned as a Software Engineer in the Banking Sector

Working in fintech has taught me invaluable lessons that extend beyond just writing code. The banking sector demands an extraordinary level of precision, security awareness, and reliability. Here are five key takeaways from my experience:

1. Security is non-negotiable. Every line of code must be written with security in mind. In financial services, a single vulnerability can have massive consequences. 2. Scale changes everything. Building for millions of transactions requires a fundamentally different approach than building for hundreds. 3. Code quality saves money. Well-tested, clean code reduces production incidents and on-call burden dramatically. 4. Communication matters as much as code. Understanding business requirements deeply leads to better technical solutions. 5. Never stop learning. Technology evolves rapidly — staying current is a professional responsibility.

Why Object-Oriented Programming Still Matters in 2026

With the rise of functional programming, serverless architectures, and AI-assisted development, some have questioned whether OOP is still relevant. As someone who earned a Coursera certification in Object Oriented Programming in Java and applies these principles daily at Barclays, I firmly believe OOP remains fundamental.

The principles of encapsulation, inheritance, and polymorphism provide powerful abstractions for modeling real-world business problems. In enterprise environments especially, well-designed object-oriented systems are easier to maintain, extend, and reason about. The key is knowing when to apply OOP principles and when other paradigms might serve better — it's about having the right tool for the right job.

Building Scalable Web Applications: Lessons from PHP to Enterprise Java

My journey in web development started with PHP — I even earned a Coursera certification in Building Web Applications in PHP. But as I moved into enterprise development, I transitioned to Java and discovered how different the requirements are at scale.

PHP taught me the importance of rapid prototyping and understanding the web request lifecycle. Java taught me about type safety, concurrent programming, and building systems that handle millions of requests reliably. Both experiences shaped me into a more versatile engineer who can evaluate technology choices based on project requirements rather than personal preference.
